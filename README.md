# رحلة الإنجليزية (Vite + React + PWA)

تطبيق يحوّل منهج السنة إلى أداة يومية: خطة اليوم، مفردات Oxford بالتكرار المتباعد، مصادر، وتتبع IELTS.

## التشغيل
    npm install
    npm run dev      # تطوير
    npm run build    # بناء في dist/

النشر على Netlify: ارفع المشروع إلى GitHub واربطه؛ ملف netlify.toml جاهز.

## الشاشات
- اليوم: قائمة مهام اليوم حسب نوعه (عمل / الأربعاء / الخميس)، والشهر الحالي وهدفه (من تاريخ البدء).
- المفردات: تعلم ومراجعة بجدول 1-3-7-14-30-60-120 يومًا، مع استيراد قوائم.
- المصادر: روابط مرتبة بالمهارة، وتُميَّز المناسبة لشهرك.
- التقدم: تسجيل اختبارات IELTS التجريبية وحساب الجاهزية، وسجل الأخطاء، والإعدادات.

## الاتصال بالمصادر
- التعريف والنطق: Free Dictionary API (api.dictionaryapi.dev)، ويُخزَّن محليًا بعد أول جلب.
- روابط مباشرة لكل كلمة في Oxford وCambridge وYouGlish.
- الاتصال مطلوب للتعريفات والنطق فقط؛ المراجعة والخطة تعملان دون اتصال.

## استيراد قوائم Oxford
من تبويب المفردات استورد ملفًا:
- نصيًا بسطر لكل كلمة مع المستوى اختياريًا: `about, A1`
- أو JSON: مصفوفة نصوص، أو كائنات بالحقول word و level و ar و example
الكلمات تُرتَّب بمستوى A1 ثم A2 فما فوق. الكلمة بلا ترجمة عربية تعرض تعريفها الإنجليزي تلقائيًا.
القوائم الرسمية: https://www.oxfordlearnersdictionaries.com/about/wordlists/oxford3000-5000

## أدوات اختيارية
- tools_build_wordlist.py: بناء قوائم من ملفات التردد.
- tools_fill_translations.py: ملء الترجمة العربية والأمثلة (يحتاج ANTHROPIC_API_KEY).
